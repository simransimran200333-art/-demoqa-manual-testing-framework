# Systematic Testing Framework Development – DemoQA Practice Form

This repository contains an academic practice study in manual test case design and defect documentation using the DemoQA Practice Form (Student Registration Form) as a publicly available training website.

## Project Overview

- Project type: Academic practice study (self-directed MCA component)
- Application under test: DemoQA Practice Form (Student Registration)
- Test techniques: Equivalence partitioning, boundary value analysis, state transition testing, exploratory testing
- Test cases: 20 (positive and negative scenarios)
- Form components analyzed: 12 (text fields, dropdowns, radio buttons, checkboxes, date picker, file upload)
- Defect reports documented: 5 (including clearly marked hypothetical scenarios for educational practice)

## Important Note on Defects

Some defect scenarios in this project are **hypothetical (HYPO-XXX)** and were created only for educational purposes, to practise professional defect documentation standards on a training website.
